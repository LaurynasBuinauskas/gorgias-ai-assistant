# SE: Refund: LOOP - SE

Tack för att du kontaktade oss! Vi är ledsna att höra att väskan inte levde upp till dina förväntningar.

För att starta returprocessen, följ stegen i vår RETURPORTAL. Där hittar du detaljerade
instruktioner tillsammans med följesedeln och returadressen.

För att vi ska kunna behandla din återbetalning snabbare ber vi dig vänligen att dela
spårningsnumret för returen med oss när paketet har skickats. Du kan enkelt svara på det här mejlet
med informationen.

Om du har några frågor eller behöver ytterligare hjälp med returprocessen, tveka inte att kontakta
oss — vi hjälper dig gärna!

# Return labels for repairs

For the EU countries, we can use FedEx, to generate return labels. For all
these shipments we use Connect Plus services.

In FedEx go to CREATE SHIPMENT and choose the option to Return shipment:
Fill the details according to the client’s details and the order/item he will return.

Make sure to fill the RMA NO. option in Return options - use the order number and the
reason for the return - REPAIR/RETURN/EXCHANGE:










If you need to create the return label outside the EU, we use Easyship.

Go to Shipments > Create:







First, “Ship from existing address” - mark “No”. Enter the first client’s details and then use the
closest warehouse address for the client’s location. For email address where to Ship To -
use our care@timeresistance.com. For the phone number use ‘-’. Press “Shipment info”






















Fill out shipment information. and press “Choose courier”



















Choose the cheapest option that includes excellent tracking and delivery confirmation. Press
“Your info”.



















At the insurance section pick “No”. Mark Drop off option and press “Payment”.

















Confirm the shipment.

















after creating the label, go to Shipments -> Label Purchased and open your created return
order.












Copy needed information (courier name, tracking information). Download the return label.

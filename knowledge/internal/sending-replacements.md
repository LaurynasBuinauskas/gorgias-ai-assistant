# How to send a replacement

We go to the original customer order and add a new product to Add product, which we are
sending as a replacement:














When we add a new product, we click on the cloud to save the new invoice:













We go to Delivery and select a new WH/Packing zone:








Through Activities, we add a message to Vaida regarding the order:










And we attach the sticker with which the replacement will be sent:
If we need to refund the shipping fee to the customer, we need to get a receipt from them
with the amount paid (the customer must use standard shipping). First, we find the order in
Odoo and to make a partial refund, we go to Invoices:


















We select Credit Note:









We enter the reason for the refund - replacement shipping and click Reverse:













We change the invoice amount to match the shipping amount paid by the customer, check
the amount in Total and click Confirm:
Then we press Register Payment > Create Payment > Send & Print:













A credit note with the refund amount for the shipment must appear with the order:







Then we return to Shopify, go to the order, and click Refund:














We enter the same refund amount as in the credit note, write - return shipping cost in the
reason and click Refund:

Reload the page and check if the refund has been made:

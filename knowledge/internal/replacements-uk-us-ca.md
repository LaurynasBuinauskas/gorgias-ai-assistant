# Replacements for UK, US and CA orders

In these cases, clients (if needed it can be done via our side as well) can fill the warranty claim
via our website > Initiate Return section. When filling the claim, if they are still eligible they
can choose the warranty option and ask for the replacements:












Once the client answers the questions, there will be an option to Replace with the same
item:









Once it is filled, we need to manually check the warranty claim via the LOOP > Returns >
Warranty processing and manually check and approve the return claim. Once it’s approved,
the return page will be active with the return label and packing slip:

























Once the client returns the item back to us with the return label, the Loop automatically will
create new order for the replacement with the format:









This order needs to be fulfilled as usual. If it’s sent from our warehouse, add the photos of
the issue if the client had a complaint to the Vaida via Odoo > Log notes.

If the client didn’t contact us, but fill the warranty form fully - with explanation and photos of
the issue, we can process the exchange without contacting him additionally.

# Creating an order in Odoo

If we need to write off a new item to bring it to the office shelf or we need to ship something
additional without the original customer order, we follow these steps to have the warehouse
move and prepare the product for us.

We go to Sales > Orders > Orders > New:






At Customer, we always find an existing customer > ZZZ support - we do not create new
customers in any way:











We add the selected item - here you cannot create new products either, but must choose
from existing options. You can also use the SKU code to search:













Since there is no payment for the product, we click on the bubble and confirm to create an
order for the store:










When the Delivery zone appears, we go to the WH/Packing Zone and leave Vaida an
activities note explaining why the item was written off and what to do with it next:



































If the product was written off to be added to the office shelf, it is necessary to add it to Excel,
delete the product we received from Missing on shelf and add it to the Newly added to shelf
section. Excel link

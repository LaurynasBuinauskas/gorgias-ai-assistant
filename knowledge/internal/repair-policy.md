# Repair policy

Priority: The customer’s experience is always our top priority. Always pay close attention to the client’s
tone and mood to ensure they don’t become overly frustrated or upset. If needed, offer alternative
solutions to help find the best possible outcome — but first, confirm any available options with the team
before responding.

            How it can be identified: from photo, order number, client name/email address.

   * We have a dedicated “Replacement Parts” listing available for all locales, accessible only via a shared link.
   When a customer requires repair parts, we provide them with the link along with the discount code REPAIR1.
   The customer then places the order. If they do not have a Shopify account, we share the global link; if they do,
   we send the link in the same website locale used for their original order. All special listing links can be found
   here: https://timeresistance.com/products/replacement-parts

   *  Once the customer has placed the order, we do not create an invoice in Odoo if the order total is €0.00.
   Instead, we simply add the repair details and photos to Vaida via Odoo Log notes and attach the shipping
   label as usual.

   Cases where the client can repair the item themselves:

       ●    Loose or lost screws, keys
       ●    Zipper puller (metal puller part only)
       ●    Lock issues (depending on the model — possible for older ones)
       ●    Loose threads (can be carefully burned off)
       ●    Jewelry box lid (can be gently massaged to help it stand properly when opened)
       ●    Strap adjustments or minor fixes
       ●    Small scratches or minor leather imperfections
       ●    Some studs (depending on the item and placement)

The Asana project for repair cases is CS: RETURNS/REPAIRS. There we track the cases in
collaboration with the warehouse.

Papildomi klausimai dėl repair
This section is used for additional repair clarifications, such as checking whether we have the
required repair part to send to the client, determining whether the repair can be done on the client’s
side or ours, assessing whether it is worth sending the item back for repair. All tasks created in this
section should be assigned to kokybe.
* Additionally, tasks are created here when a repair part needs to be sent to a client who contacted us via Etsy or Amazon. In these
cases, the shipping label should also be attached to the task.

REPAIR
This section is for all cases where the item has reached our headquarters and is ready for the repair
process, or when the client is sending the return package for repair directly to our headquarters.
The task should be assigned to kokybe when the package is expected to arrive soon or has already
arrived, indicating that the item is in the repair process. Once the repair is completed, Vaida will
assign the task to the agent. The agent then uploads the shipping label and reassigns the task to
kokybe to confirm that the repaired item is ready to be shipped back to the client.

REPAIR, ne į LT siųsta
This section tracks all tasks where we have received a tracking number from the client indicating
that the return package for repair is on its way. The task should remain assigned to the agent until
the tracking confirms that the package has been delivered to the warehouse. Once the delivery is
confirmed, update the Status section with the warehouse location and remove the assignee from the
task.

Tik patvirtinti, kad grįžo mums
This section is for cases where we send return labels to clients from our side, created via FedEx.
The task should be assigned to the agent until the return package is in transit. Once the package is
confirmed to be in transit, the task should be reassigned to kokybe for further tracking and
processing.

FedEx grąžinamos siuntos
This section is for tasks created when FedEx informs us that a package was not delivered and is
being returned. The task should remain assigned to the agent, who is responsible for contacting the
client to determine whether the order should be resent (possibly to an alternative address) or if the
client no longer wants it. If the client does not respond within two weeks, the task should be
assigned to kokybe, noting that the client either refused the package or did not respond, and the
package can then be returned to stock.

REPAIR - pending/SHIPPING - pending
This section is for cases where the client needs to send us a return package for
repair/exchange/replacement, but we are still waiting for a tracking number. The task should remain
assigned to the agent until the tracking number is received. Once the tracking number is available,
the task should be moved to either REPAIR or REPAIR – ne į LT siųsta, depending on the situation.
Alternative, if it’s not a repair, then to Warranty cases (ne į LT)

Warranty cases (ne į LT)
This section for all returns/exchanges/replacements, when the client ships the item back to our
warehouses.
Another Asana project - CS: Returns with incomplete address
This project is for cases where the client provides a tracking number, but it does not show correct
delivery details, or the client used an incomplete address. For Australia specifically, this includes
cases where the client simply left the package at the warehouse without using a shipping service.

one. In this case, in the Asana’s CS: RETURNS/REPAIRS we have the task on the top: DIRŽELIAI -
pardavimui/siuntimui:












Use this task to check if we have the extra leather strap that we can send to the client. If not sure,
just ask for kokybe in the same task. That way, the information will be visible to everyone.

When sending the leather strap for the client, we have the listing on each locale -
https://timeresistance.com/products/leather-strap-replacement
The listing is visible to everyone, however we can only fulfill the order when it's placed, only if the
client contacted us or left a note with the bag’s model and color in order to check if we have the
available strap for shipping.
